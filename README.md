# Animated History Studio

Animated history shorts with 2D cartoon characters in a Three.js world, rendered by Remotion and GitHub Actions.

This repository is being bootstrapped from the open-source [claude-animated-shorts](https://github.com/mromidev/claude-animated-shorts) workflow (MIT). The demo is an original short about Pompeii, AD 79.

**Render:** GitHub Actions > Render animation > Run workflow. See documentation after project setup.
